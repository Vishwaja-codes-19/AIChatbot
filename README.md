**AI Chatbot**

A Java-based rule-driven chatbot that uses text preprocessing, keyword matching, and a knowledge base to provide responses to user questions.

**Features**

- Interactive console-based communication
- Rule-based chatbot responses
- FAQ knowledge base
- Text preprocessing
- Keyword-based question matching
- Java programming-related responses
- OOP and DSA explanations
- SQL and DBMS information
- GitHub and programming-related responses
- Continuous conversation until exit

**Technologies Used**

- Java
- Object-Oriented Programming
- HashMap
- Scanner
- String Processing
- Git & GitHub

**Project Structure**

AI-Chatbot/
├── Main.java
└── README.md

**How to Run**

Compile the Java program:

javac Main.java

Run the chatbot:

java Main

**How It Works**

1. The user enters a question or message.
2. The chatbot preprocesses the input by converting it to lowercase and removing unnecessary characters.
3. The chatbot checks the input for recognized keywords.
4. The corresponding response is retrieved from the knowledge base.
5. The chatbot displays the response.
6. The conversation continues until the user enters an exit command.

**Sample Questions**

- Hi
- What is Java?
- Explain OOP
- What is DSA?
- What is an array?
- What is SQL?
- What is DBMS?
- What is GitHub?
- What is this project?
- What is programming?
